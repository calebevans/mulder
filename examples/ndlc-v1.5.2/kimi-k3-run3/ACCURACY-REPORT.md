## Analysis of Misses and Errors

### What changed against run 1 on the same image

The extractor output the model consumed is unchanged (`tsk.masquerade` 0 / 17 / 3 lines on rm1 / rm2 / PC, `optical.listing` 58 lines). What differs is what the model did with it.
